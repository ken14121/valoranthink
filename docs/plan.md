# 企画メモ：VALORANT の立ち回りを AI が手伝うツール

## アイデア
- 撃ち合い（エイム）は自分でやる。AI は「立ち回り」の判断だけを手伝う（「B に寄るべきか」「今は待つべきか」）。
- プロや上位ランクの立ち回りを参考にした判断をさせたい。
- 判断には Jev（TypeSafe AI の判断モデル、`@typesafe-ai/sdk`）を使う。

## 前提・守ること
- 画面を読んでマウスやキーを操作する bot は作らない。操作するのはあくまで本人。
- Riot の許可の範囲で作る。許可なしで対戦に使うのは規約違反で、Vanguard で BAN される。
- 試合データを公式 API から取るには Riot の承認が必要。承認がないうちは自分の録画から手入力で作る。

## Riot のポリシー（2026-10-08 時点で調べたこと）
- 「ランクじゃなければ大丈夫」という回答をもらった。**誰からの回答か・書面で残っているかを記録しておく。**
- 一方、Riot の公開ポリシーでは、**試合中に「結論を出してあげる」アプリ**（Drawing conclusions for you during gameplay）は
  有利を与えるものとして挙げられていて、ランク/アンレートの区別は書かれていない。
  - 出典: https://support-leagueoflegends.riotgames.com/hc/en-us/articles/225266848
  - 出典: https://support.riotgames.com/en-us/valorant/account/third-party-applications
- Vanguard はモードに関係なく動いている。試合中に画面を読むプログラムを動かすと、アンレートでも検知される可能性はある。
- **試合後の振り返り（録画を見て手入力 → Jev）は、試合中に何も動かさないので、この心配がない。** まずこちらを作る。
- 試合中の補助（リアルタイム）に進むなら、その前に Riot から書面で、対象モード（カスタム／アンレート）と
  やり方（画面読み取り・オーバーレイ・音声）まで含めて許可をもらう。

## 組み立て
| 役割 | 何をする | 担当 |
|---|---|---|
| 状況を読む | 録画から、ラウンドの迷った場面を JSON に書き写す（のちに画像認識） | 手入力 → コード |
| 決まっていることを決める | 死んでいる・設置後の守備など、答えが決まっている場面は Jev に聞かない | `src/rules.ts` |
| 判断する | 「寄るべきだったか」「10 秒早く動けたか」をはい/いいえ（Noul）で聞く | Jev（`src/ask.ts`） |
| 伝える | ラウンドごとの一覧。確かさ 0.7 未満は「要確認」 | `src/review.ts` |

## 旅行記録 app で Jev を使って分かったこと（ここにも反映済み）
- Choice より Noul を組み合わせる（Choice は選択肢の順番で偏ることがある）。
- 数えられることはコードで決め、迷う判断だけ Jev に聞く。
- 判断の道筋で一番低い確率を「確かさ」にし、0.7 未満は「要確認」。
- 本人の答えと比べる（正解率・外れた場面・確率の当たり具合）。外れ方を見て、判断基準を質問文に書き足す。

## 注意
- 今の Jev の API キーは臨地実習で借りているもの（上限 $5 の共有）。**このプロジェクトで使う前に、ゆうへいさんに確認する。**
  - 確認が取れるまでは `--dry-run`（キーなしでも自動で dry-run になる）で、送る内容だけ確認する。
- API キーは `.env.local` に置く（`.gitignore` 済み）。GitHub やチャットには貼らない。
